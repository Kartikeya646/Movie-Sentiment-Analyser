# Movie-Sentiment-Analyser
AI-powered Movie Sentiment Analyzer built with HTML, CSS, Node.js, Gemini API, and movie database APIs. Features autocomplete search, movie posters, ratings, AI-classified sentiment visualization, plot summaries, and AI-generated review insights from API data or live Google reviews.

Methods to use the application:
1. Download all the files and put it in a single folder.
2. Take the folder location and open it in cmd and type 'npm install' in order to create the node_modules folder.
3. Go to index.html and put your own gemini api key and url and lines 425 and 426.
4. Go to command prompt and go to the folder location and type node server.js.
5. Then select the local host site from the pop up to access the frontend.
6. Search your favorite movies and see those reviews.
